# Трёхконтурное бесконтактное зажигание {#three-circuit-bsz}

Три независимых контура для **шестицилиндровых** двигателей работают по тому же принципу, что и [двухконтурная система с холостой искрой](dual-circuit.md): на каждую **пару** цилиндров один контур (рабочая и «холостая» искра в такте). Отличие от «классического» двухконтурного четырёхцилиндрового варианта — число пар: у шести цилиндров их три, значит три датчика Холла, три коммутатора [76.3774](../../components/commutator-763774.md) и согласованная разводка по вашей схеме.

По смыслу это масштабирование идеи [двухконтурного БСЗ](dual-circuit.md); для восьми цилиндров см. [четырёхконтурное БСЗ](four-circuit.md) — там четыре таких же контура.
