# Сборка системы по схеме {#build-circuit-bsz}

Пошаговое руководство: от подбора комплекта до рабочего зажигания.

## 1. Подобрать комплект и закупить компоненты {#kit-and-parts}

1. Определите комплект под маркировку трамблёра: [Как определить необходимый комплект БСЗ](../kits/how-to-choose-kit.md).
2. Соберите корзину по типу вашей системы: [типовой список для сборки БСЗ](../components/buy-list.md) (одно-, двух-, трёх- или четырёхконтурный перечень).

## 2. Выбрать тип схемы по мотору и задаче {#choose-circuit-type}

- **Один контур** — [одноконтурное БСЗ](../theory/single-circuit.md).
- **Два контура** (холостая искра) — [двухконтурное БСЗ](../theory/dual-circuit.md).
- **Три контура** — шесть цилиндров - [трёхконтурное БСЗ](../theory/three-circuit.md).
- **Четыре контура** — восемь цилиндров - [четырёхконтурное БСЗ](../theory/four-circuit.md).

Откройте соответствующую статью — там типовая схема и пояснения к узлам.

- **Подключение тахометра** — для систем с двумя и более контурами: [инструкция](tachometer-connection.md).

## 3. Собрать, проверить, настроить {#assemble-verify-tune}

- Если что-то ведёт себя не так — [проблемы и решения](problems-and-solutions.md).
