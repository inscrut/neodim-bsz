# Доработка датчика Холла {#hall-sensor-mod}

Подготовка заводского датчика Холла ВАЗ 2108 под комплекты Неодим: снятие родного магнита, проверка полярности, посадка в держатель.

Подробности об устройстве прибора и полярности — в разделе [Датчик Холла](components/hall-sensor.md). Проверку правильности доработки после установки удобно выполнить по [алгоритму проверки БСЗ](bsz-check-algorithm.md).
