# Компоненты {#components-index}

Детали, которые докупаются к комплектам Неодим для полной сборки бесконтактной системы зажигания.

## Что нужно купить {#what-to-buy}

Количество компонентов зависит от типа системы (1/2/3/4 контура). Полный чеклист с артикулами — [Типовой список для сборки БСЗ](buy-list.md).

## Компоненты системы {#components-cards}

<div class="grid cards" markdown>

-   :material-magnet: **[Датчик Холла](hall-sensor.md)**

    А473.407529.002 (ВАЗ 2108). Устройство, полярность, доработка под комплекты.

-   :material-chip: **[Коммутатор 76.3774](commutator-763774.md)**

    Одноканальный силовой модуль ООО «РОМБ». Подключение, подлинность.

-   :material-flash: **[Катушки зажигания](ignition-coils.md)**

    HOFER HF750301/313/304 под одно-, двух- и четырёхконтурные схемы.

-   :material-cable-data: **[Жгут проводки БСЗ](wiring-harness-dbsz.md)**

    ВАЗ 2105/2121, самодельный жгут на два контура, готовый жгут Неодим.

-   :material-stethoscope: **[МД-1 — мгновенная диагностика](md-1.md)**

    Прибор для настройки зажигания и диагностики. Порядок работы.

-   :material-cart-arrow-down: **[Типовой список для сборки БСЗ](buy-list.md)**

    Сводный чеклист по количеству компонентов для 1/2/3/4 контуров.

</div>
