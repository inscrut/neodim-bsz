# Типовой список для сборки БСЗ системы {#bsz-shopping-list}

Мы занимаемся только производством комплектов для переделки распределителей зажигания — подбор комплекта:

[Как определить необходимый комплект БСЗ](../kits/how-to-choose-kit.md).

Для сборки полной системы зажигания вам необходимо приобрести у других производителей или продавцов следующие комплектующие:


- [Датчик Холла](hall-sensor.md)
- [Коммутатор 76.3774](commutator-763774.md)
- [Катушка зажигания](ignition-coils.md)
- [Жгут проводки БСЗ](wiring-harness-dbsz.md)

Рекомендуем собрать недостающее на [Ozon](https://www.ozon.ru/), либо в магазинах автозапчастей.

Необходимое количество зависит от типа системы зажигания — выберите нужную вкладку ниже.

---

## Комплектации по числу контуров {#circuits-tabs}

### Одноконтурная система зажигания {#parts-single-circuit}

Базовая замена КСЗ: один датчик Холла, один коммутатор, одна катушка. Принципиальная схема — [одноконтурное БСЗ](../guide/schemes/single-circuit.md).

| Компонент | Количество | Примечание |
|-----------|------------|------------|
| [Датчик Холла АО «Автоэлектроника» от ВАЗ 2108](hall-sensor.md) | 1 шт. | **А473.407529.002**. |
| [Коммутатор 76.3774 РОМБ](commutator-763774.md) | 1 шт. | |
| [Катушка зажигания](ignition-coils.md#coils-single-circuit) | 1 шт. | **HOFER HF 750 301** |
| [Жгут проводки БСЗ](wiring-harness-dbsz.md) | 1 шт. | ВАЗ 2105 **2105-3724026-20** (стандарт) или ВАЗ 2121 **2121-3724026** (длиннее) |
| Комплект бронепроводов | 1 комплект (опционально) | При проводах «нулевого сопротивления» свечи должны быть со встроенным резистором (часто маркировка **R**). |
| [Комплект Неодим](../kits/how-to-choose-kit.md) под ваш трамблёр | 1 шт. | |


### Двухконтурная система зажигания {#parts-dual-circuit}

«Холостая искра» (wasted spark) для 4-цилиндровых моторов. Два датчика, два коммутатора, модуль ВАЗ 2111 или две катушки ЗМЗ 406. Принципиальная схема — [двухконтурное БСЗ](../guide/schemes/dual-circuit.md).

| Компонент | Количество | Примечание |
|-----------|------------|------------|
| [Датчик Холла АО «Автоэлектроника» от ВАЗ 2108](hall-sensor.md) | 2 шт. | **А473.407529.002**. |
| [Коммутатор 76.3774 РОМБ](commutator-763774.md) | 2 шт. | |
| [Модуль зажигания ВАЗ 2111](ignition-coils.md#coils-dual-circuit) | 1 шт. | **2111-3705010-03**. Разъём на 3 контакта **ДАП-107.3724.030-01** — 1 шт. Либо **две** катушки ЗМЗ 406 **406.3705** — см. [катушки зажигания, двухконтурная система](ignition-coils.md#coils-dual-circuit). |
| [Жгут проводки БСЗ](wiring-harness-dbsz.md) | 2 шт. | ВАЗ 2105 **2105-3724026-20** (стандарт) или ВАЗ 2121 **2121-3724026** (длиннее) |
| Комплект бронепроводов от инжекторного ВАЗ 2107 / 2112 | 1 комплект | При проводах «нулевого сопротивления» свечи должны быть со встроенным резистором (часто маркировка **R**). |
| [Комплект Неодим](../kits/how-to-choose-kit.md) под ваш трамблёр | 1 шт. | |
| Крышка с креплением двух разъёмов датчиков Холла ВАЗ 2108 | 1 шт. (опционально) | |


### Трёхконтурная система зажигания {#parts-three-circuit}

Для 6-цилиндровых двигателей: три пары цилиндров, три контура. Принципиальная схема — [трёхконтурное БСЗ](../guide/schemes/three-circuit.md).

| Компонент | Количество | Примечание |
|-----------|------------|------------|
| [Датчик Холла АО «Автоэлектроника» от ВАЗ 2108](hall-sensor.md) | 3 шт. | **А473.407529.002**. |
| [Коммутатор 76.3774 РОМБ](commutator-763774.md) | 3 шт. | |
| [Катушки ЗМЗ 406 **406.3705**](ignition-coils.md#coils-four-circuit). | 3 шт. |  |
| [Жгут проводки БСЗ](wiring-harness-dbsz.md) | 3 шт. | ВАЗ 2105 **2105-3724026-20** (стандарт) или ВАЗ 2121 **2121-3724026** (длиннее) |
| Комплект бронепроводов | 1 комплект | При проводах «нулевого сопротивления» свечи должны быть со встроенным резистором (часто маркировка **R**). |
| [Комплект Неодим](../kits/how-to-choose-kit.md) под ваш трамблёр | 1 шт. |  |
| Крышка с креплением разъёмов датчиков Холла | 1 шт. (опционально) |  |


### Четырёхконтурная система зажигания {#parts-four-circuit}

Для 8-цилиндровых двигателей: количество компонентов в **два раза** больше, чем у двухконтурной. Принципиальная схема — [четырёхконтурное БСЗ](../guide/schemes/four-circuit.md).

| Компонент | Количество | Примечание |
|-----------|------------|------------|
| [Датчик Холла АО «Автоэлектроника» от ВАЗ 2108](hall-sensor.md) | 4 шт. | **А473.407529.002**. |
| [Коммутатор 76.3774 РОМБ](commutator-763774.md) | 4 шт. | |
| [Модуль зажигания ВАЗ 2111](ignition-coils.md#coils-dual-circuit) | 2 шт. | **2111-3705010-03**. Разъём **ДАП-107.3724.030-01** — 2 шт. Либо **четыре** катушки ЗМЗ 406 **406.3705** — см. [катушки зажигания, четырёхконтурная система](ignition-coils.md#coils-four-circuit). |
| [Жгут проводки БСЗ](wiring-harness-dbsz.md) (ВАЗ 2105 **2105-3724026-20** или ВАЗ 2121 **2121-3724026**) | 4 шт. | |
| Комплект бронепроводов | 1 комплект | При проводах «нулевого сопротивления» свечи должны быть со встроенным резистором (часто маркировка **R**). |
| [Комплект Неодим](../kits/how-to-choose-kit.md) под ваш трамблёр | 1 шт. |  |
| Крышка с креплением разъёмов датчиков Холла для четырёхконтурного БСЗ | 1 шт. (опционально) | См. [крышка v2 (четырёхконтурный БСЗ)](../kits/zil-gaz-v8.md#cover-v2-four-circuit). |
