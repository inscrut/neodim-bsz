# Наборы БСЗ Неодим {#kits-index}

Комплекты для переделки контактных трамблёров в бесконтактные — с сохранением заводского угла опережения зажигания.

## С чего начать {#how-to-start}

- Не знаете, какой комплект нужен — [Как определить необходимый комплект БСЗ](how-to-choose-kit.md).
- Знаете маркировку трамблёра — выбирайте в разделе [Распределители зажигания](distributors/index.md).
- Знаете модель автомобиля — выбирайте ниже.
