## Как опознать свой трамблёр {#identify}

1. Снимите крышку, очистите корпус снизу — там нанесена маркировка.
2. Сверьте цифры с таблицей выше.
3. Сравните внешний вид с фото на странице соответствующей модели.
4. Если сомневаетесь — [Как определить необходимый комплект БСЗ](../kits/how-to-choose-kit.md).
